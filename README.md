# Telegram-бот для приёма заявок

Бот принимает заявки от пользователей, сохраняет в SQLite и присылает уведомление администратору в Telegram.

## Возможности
- Приём заявок через кнопку или текстом
- Сохранение в SQLite (без внешних сервисов)
- Мгновенное уведомление администратору
- Админ-команда `/admin` — статистика и последние 5 заявок
- Работа через SOCKS5-прокси (актуально для РФ)

## Технологии
- Python 3.10+
- Aiogram 3
- SQLite
- aiohttp_socks

## Установка и запуск
1. Установить зависимости:
   pip install aiogram aiohttp_socks
2. Получить токен у @BotFather → вставить в `BOT_TOKEN`.
3. Узнать свой Telegram ID у @userinfobot → вставить в `ADMIN_ID`.
4. (Опционально) Указать SOCKS5-прокси в `PROXY`.
5. Запустить:
   python bot.py
